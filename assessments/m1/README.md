# Introduction to Embedded Systems Software and Development Environments

## Author
Noel Varghese

## Project Description
This repository contains my implementation for Assignment 1 of the
Introduction to Embedded Systems Software and Development Environments
course offered by the University of Colorado Boulder.

The project implements a simple statistical analysis application in C.
It calculates and displays the minimum, maximum, mean, and median of a
dataset and sorts the dataset from largest to smallest.

The project is developed and tested on a Linux host machine using GCC
and Git for version control.
